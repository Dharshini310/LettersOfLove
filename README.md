# 💌 Letters Of Love

A beautiful and personalized birthday wishes website built using the **MERN Stack**, **React Router**, **Lottie Animations**, and custom video experiences.

🌐 Live Demo: letters-of-love-oo5w.vercel.app

---

 ## 📖 About The Project

**Letters Of Love** is a unique birthday wishes website designed to create a memorable and emotional experience through animations, videos, and interactive navigation.

The project combines modern web technologies with creative storytelling to deliver personalized birthday messages in an engaging way.

Every page is carefully designed with smooth transitions, animated elements, and heartfelt content to make the birthday celebration feel special.

## 🎬 Special Highlights

### 🌊 Wave Loader Animation

Before displaying each video clip, a custom loader screen is shown where the letters move in a smooth wave motion, creating an engaging transition experience.

### 🎭 Lottie File Integration

Lottie animations are used throughout the website to bring pages to life and create visually appealing interactions.

### 🔄 Navigation Using useNavigate

Instead of using traditional `NavLink` or `Link` components, the website utilizes React Router's `useNavigate` hook for programmatic navigation and enhanced user flow control.

## 🔧 Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project folder:

```bash
cd letters-of-love
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
